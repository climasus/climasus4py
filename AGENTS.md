# AGENTS.md

As instruções para **qualquer agente de IA** atuando neste repositório (Codex, Cursor, Copilot, etc.) estão em [`CLAUDE.md`](CLAUDE.md).

Leia o arquivo integralmente antes de qualquer tarefa. Em resumo, ele define:

1. A missão do ecossistema ClimaSUS e o lugar deste pacote nele.
2. Princípios duros: lazy ponta a ponta (DuckDB), metadados só em `climasus-data`, paridade de API com `climasus4r`, evidência acima de suposição.
3. Fronteiras de segurança: sem git destrutivo, sem segredos, sem mudança de API pública ou publicação sem aprovação humana.
4. Convenções: respostas em PT-BR, código/docstrings em inglês, Conventional Commits, `CHANGELOG.md` e `IDEIAS.md`.
